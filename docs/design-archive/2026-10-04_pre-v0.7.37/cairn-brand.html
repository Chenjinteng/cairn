The Mark

// 一座石堆 / A wayfinder

Cairn(石堆)是荒野旅人用来标记路径的石塔 —— 在没有路标的地方,最先出现的人造物。 Logo 以三块圆角矩形堆叠成塔身,顶部一颗琥珀色圆点表示「标记」本身。 三块石头对应 cairn 三个核心能力面:镜像管理 / 拉取 / GC; 琥珀点代表「目标服务器的位置标记」,也是 cairn 的导航功能。

几何形态刻意抽象化:不是写实石块,也不是 Docker 鲸鱼这种具象标志 —— 它代表「中立的容器镜像基础设施」,跟 Docker / Quay / Harbor 等任何具体 registry 实现解耦。

Construction

// 几何构成 / Geometry
  • 01
    基座 Base Stone
    52u 宽 × 16u 高 — 最大、最稳。代表「镜像存储」与持久层。
  • 02
    中层 Middle Stone
    36u 宽 × 13u 高 — 比基座窄一圈,代表「拉取 / 拉取队列」中段。
  • 03
    顶层 Top Stone
    20u 宽 × 9u 高 — 最窄,代表「UI / 配置」层,操作员最接近的面。
  • 04
    标记点 The Marker
    琥珀色圆点 — 整座石塔的目的:让别人看见「这里有路标」。
