Typography

// 三字体系统 · Display / UI / Mono

DM Serif Display 用于大标题与品牌字 — 标题与正文之间形成"编辑型"对比; Outfit 是 UI 主字体 — sans-serif 几何感,信息密集时仍清晰; JetBrains Mono 用于 hash / digest / 时间戳 / 字段 key — monospace 让技术信息天然对齐。

Spacing & Layout

// 8px 基线网格 · 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64
