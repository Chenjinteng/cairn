Cairn Logo · 动画方案对比

3 种风格 · 各有 1 次入场 + 持续呼吸 + hover 微交互

A · 石塔建造

从下往上逐层堆,最后琥珀点弹性落入。强隐喻,故事感。

B · 整体浮动

分层淡入后整体呼吸浮动。更克制,优雅感。

C · 擦除堆叠

从右往左擦除出现,弹跳入点。工业感强,节奏快。
怎么预览: 在浏览器打开这个文件(file://...),三个 logo 都会自动播一次入场动画。 点「重播」重新触发;鼠标移到 logo 上看 hover 微交互;琥珀点会持续呼吸。

下一步: 挑一个方案,把它合并到 web/public/cairn-intro.html hero SVG,加 class + 注入 CSS 块。 静态 fallback(无 CSS 加载或 prefers-reduced-motion: reduce)用 animation: none 兜底, logo 仍然完整可见。
