与源码的对应关系

// design ↔ code · 同步关系

UI 设计稿与 cairn 实际 web 是单一来源双向同步:

// design → code
改 demo → 同步
  • theme.css 的颜色 token
  • main.tsx 的 antd theme config
  • cairn-mark.tsx 的 SVG fill
// code → design
改源码 → 同步
  • 任何 token 改名 / 新增
  • 任何组件样式大调(圆角 / 阴影 / 字号)
  • 任何新页面 / 新区块（v0.5.40+ sync 页就是这条触发）
  • 侧栏分组重做（v0.5.37.4 onPublishGroups 上浮协议）
  • 字体栈变更（v0.5.38 去 CDN,改 system stack）
