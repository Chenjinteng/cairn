## 唯一缺陷与修复

| 项 | 内容 |
| --- | --- |
| 现象 | `images-page` 步13「断言确认运行 GC 弹窗」超时 5277ms → failed |
| 根因 | 断言选择器命中 DOM 中**已关闭的旧弹窗**。runner 的 css 定位非 strict、取首个匹配（`test-runner/src/runner.js:51` resolveLocator、`:85` runStep）；antd 弹窗关闭后节点永久驻留 DOM（仅加 `.ant-popover-hidden`） |
| 修复 | 弹窗类断言/点击统一加 `:not(.ant-popover-hidden)` 作用域，共 4 处：步10 `:116`、步11 `:123-124`、步13 `:142`、步14 `:149-150` |
| 验证 | 单场景复跑 15/15，步13 **5277ms → 83ms** |
| 提交 | `ab5744f`（6 files changed, +369 / −237），已 push，`origin/main...HEAD = 0 0` |
